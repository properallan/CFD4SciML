# Discontinuous Galerkin Method - References

Repositório colaborativo para organização de artigos, livros, teses e materiais relacionados ao Método de Galerkin Descontínuo (DG).

O objetivo é manter uma base organizada de referências para estudo, desenvolvimento e aplicação do método.

---

## Organização
Os arquivos estão disponíveis na pasta [Fundamentals](./Fundamentals) e são organizados em subpastas de acordo com seu tópico, no momento o acervo contém:

📂 Fundamentals  
|--- 📁 Aplicacoes  
|--- 📁 Introductions_and_Reviews  
|--- 📁 RKSSP  
|--- 📁 Solvers  
|--- 📁 Shock

**Nota:** Devido a limitações de tamanho, os livros não serão adicionados ao repositório, porém ficarão indicados para: leitura, obtenção e/ou referência.

# Como contribuir

Ao adicionar uma nova referência:

2. Atualize o README da categoria;
3. Adicione a entrada BibTeX no arquivo adequado;
4. Inclua um breve resumo.
